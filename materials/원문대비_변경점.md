## 0. 숫자 대조 (기계 검사)
본문에서 숫자를 모두 뽑아 원문과 비교한 결과(낱말 풀이·확인 질문 제외)

| 파일 | 원문에 있으나 빠진 숫자 | 원문에 없이 새로 생긴 숫자 | 값이 바뀐 숫자 |
|---|---|---|---|
| 기초 | 2018·2019·2020(GPT-1·BERT·GPT-3 연도), 768·3072(MLP 크기) | 없음 | **없음** |
| 보통 | 없음 | 없음 | **없음** |
| 심화 | 없음 | 50,257(GPT-2 어휘 수) | **없음** |
| 다문화 | 1986·1997·2014(RNN·LSTM·Seq2Seq 연도), 2018·2019·2020, 768·3072 | 없음 | **없음** |

## 1. 공통 사항 (4개 파일 모두)
| 원문 | 변경 | 유형 | 판정 |
|---|---|---|---|
| 끝의 「직접 해 보기」 실습 사이트 2곳 | 넣지 않음 | 생략 | ✅ |
| 낱말 풀이·확인 질문 없음 | 수준마다 낱말 풀이 3개, 확인 질문 2개(객관식 1·서술형 1), 교사용 정답 추가 | 구성 | ✅ |
| 머리말 없음 | 대상(고2)·수준·원문 링크 표시 | 구성 | ✅ |

## 4. 심화
원문의 사실은 모두 유지하고, **표준 정의에 따른 보충 설명(본문에 ➕ 표시, 12곳)**을 더함.

| 절 | 원문 | 심화 | 유형 | 판정 |
|---|---|---|---|---|
| 1 | "문장이 길어질수록 벡터 하나에 모든 내용을 담기 어려웠다" | "고정 크기 벡터에 정보를 담다 보니 문장이 길어질수록 정보가 손실되는 한계" | 쉬운 말(전문 표현) | ✅ |
| 1 | "그래서 트랜스포머를 'GPT의 어머니'라고 부른다" | 넣지 않음(제목에만 있음) | 생략 | ✅ |
| 2 | 원-핫은 "단어 사이의 관계를 담지 못한다" | ➕ 이유 보충: "모든 단어 벡터가 서로 같은 거리에 있기 때문" | 보충 | ✅ |
| 2 | — | ➕ 원-핫 벡터 길이 = 어휘 수, GPT-2 어휘 50,257개 | 보충 | ✅ |
| 2 | — | ➕ GPT-2(small) 임베딩 차원 768 | 보충 | ✅ (원문 3절 768과 같은 값) |
| 2 | "'왕'의 의미에서 …'여왕'이 나온다" | 넣지 않음 | 생략 | ✅ |
| 3① | "임베딩만으로는 단어의 순서를 알 수 없다" | ➕ "어텐션 계산 자체는 토큰의 순서를 구분하지 못한다" | 보충 | ✅ |
| 3① | "각 토큰의 임베딩에 위치 정보를 더한다" | ➕ GPT-2는 학습되는 위치 임베딩을 더하는 방식 | 보충 | ✅ |
| 3② | "각 단어가 다른 단어를 얼마나 참고해야 하는지 계산" | ➕ Query·Key·Value, 수식 softmax(QKᵀ/√dₖ)V | 보충 | ✅ |
| 3② | — | ➕ masked self-attention(앞 토큰만 참조) | 보충 | ✅ |
| 3② | "여러 개의 헤드" | ➕ GPT-2 small은 블록마다 12개 | 보충 | ✅ |
| 3② | "맡도록 나뉜다" | "포착하도록 분업화된다" | 쉬운 말(전문 표현) | ✅ |
| 3③ | "768개였던 숫자를 3072개로", "단순한 직선 계산" | "768차원 → 3072차원", "선형 변환" | 쉬운 말(전문 표현) | ✅ |
| 4 | "틀린 만큼 숫자(파라미터)를 고친다" | ➕ 교차 엔트로피 손실, 경사 하강법 | 보충 | ✅ |
| 5 | "모든 후보 토큰에 확률을 매기고 그중 하나를 고른다" | ➕ 출력 → logit → softmax → 확률 분포에서 선택 | 보충 | ✅ |
| 6 | 온도를 낮추면 안정, 높이면 다양 + 환각 증가 | ➕ 수식 pᵢ = exp(zᵢ/T) / Σⱼ exp(zⱼ/T), T<1 뾰족·T>1 평평 | 보충 | ✅ (원문 서술과 같은 방향) |

## 6. 요약
- **값이 바뀐 사실·수치: 0건** (숫자 대조 + 문장 대조)
- 교사 확인 권장(⚠️) 1건: 다문화 7절에서 '토큰'을 '단어'로 바꿔 씀(쉬운 말 단순화)
- 작성 중 고친 곳 2건: 다문화 3절 "12번 반복" → "층(블록)을 12개 쌓았습니다", 심화 2절 보충 설명에 ➕ 표시 추가
- 기초·다문화는 **생략**이 대부분, 보통은 문장 다듬기, 심화는 **보충**(➕ 12곳)이 대부분
- 확인 질문·낱말 풀이의 베트남어·중국어 뜻은 원어민 교사나 사전으로 한 번 더 확인 권장
