# [심화] GPT의 어머니, 트랜스포머

> 대상: 고등학교 2학년 · 수준: 심화 · 원문: [원문_트랜스포머_v2.md](../원문_트랜스포머_v2.md)
> 원문에 없는 보충 설명은 ➕ 표시. 보충 내용은 GPT-2 공개 사양과 트랜스포머 논문의 표준 정의를 따름

## 1. 순차 처리에서 어텐션으로
RNN(1986)과 LSTM(1997)은 토큰을 앞에서부터 하나씩 순차적으로 처리했다. Seq2Seq(2014)는 입력 문장 전체를 고정된 크기의 context vector 하나로 압축해 번역에 썼다. 고정 크기 벡터에 정보를 담다 보니 문장이 길어질수록 정보가 손실되는 한계가 있었다.

어텐션(Attention, 2015)은 입력 시퀀스 전체를 참조하면서 지금 필요한 토큰에 더 큰 비중을 둔다. 2017년 어텐션만으로 구성한 트랜스포머(Transformer)가 발표되었고, GPT-1(2018), BERT(2019), GPT-3(2020)가 모두 이 구조를 바탕으로 한다.

## 2. 토큰과 벡터 표현
챗GPT, 클로드, 제미나이는 입력 텍스트를 토큰으로 나누고 각 토큰을 벡터로 바꾼다.

원-핫 인코딩은 '나는' = [1, 0, 0, 0, 0], '공부를' = [0, 0, 1, 0, 0]처럼 자기 자리만 1인 벡터다. 단어 사이의 관계를 표현하지 못한다. ➕ 모든 단어 벡터가 서로 같은 거리에 있기 때문이다. ➕ 벡터 길이도 어휘 수만큼 길어진다(GPT-2의 어휘는 50,257개 토큰).

임베딩은 토큰을 '나는' = [0.123, -0.411, 0.345, …]처럼 실수 벡터로 나타낸다. ➕ GPT-2(small)의 임베딩 차원은 768이다. 뜻이 비슷한 단어는 벡터 공간에서 가까이 놓이며('computer' 근처에 'computers', 'software', 'laptop'), 벡터 연산 'King − Man + Woman'의 결과는 'Queen'의 벡터에 가까워진다.

## 3. 트랜스포머 블록의 구조 (GPT-2 기준)
**① 포지셔널 인코딩** — ➕ 어텐션 계산 자체는 토큰의 순서를 구분하지 못한다. 그래서 각 토큰 임베딩에 위치 정보를 더해 '나는 너를 좋아한다'와 '너는 나를 좋아한다'를 구별한다. ➕ GPT-2는 위치마다 학습되는 위치 임베딩을 더하는 방식을 쓴다.

**② 멀티헤드 어텐션** — 각 토큰이 다른 토큰을 얼마나 참고할지 계산한다.
- ➕ 토큰마다 Query(Q), Key(K), Value(V) 벡터를 만들고, Q와 K의 내적으로 관련도 점수를 구한 뒤 softmax로 가중치(합 1)를 만들어 V를 가중합한다: Attention(Q, K, V) = softmax(QKᵀ / √dₖ)V
- ➕ GPT-2는 다음 단어를 예측하는 모델이므로 각 토큰이 자기 앞의 토큰만 보도록 뒤쪽을 가린다(masked self-attention).
- 여러 헤드가 이 계산을 동시에 한다(➕ GPT-2 small은 블록마다 12개). 헤드는 무작위로 초기화되지만 학습을 거치며 문법 구조, 의미 관계, 위치 패턴처럼 서로 다른 언어 특징을 포착하도록 분업화된다.

**③ 다층 퍼셉트론(MLP)** — 어텐션이 토큰 사이의 관계를 모았다면 MLP는 각 토큰의 표현을 독립적으로 다듬는다. 768차원을 3072차원으로 늘렸다가 다시 768차원으로 줄이며, 그 사이에 비선형 활성화 함수 GELU를 써서 선형 변환만으로는 표현할 수 없는 패턴을 학습한다.

GPT-2(small)는 이 블록을 12개 쌓는다.

## 4. 학습: 다음 토큰 예측
학습은 지도학습이다. 문장 앞부분을 주고 다음 단어를 맞히게 한 뒤 정답과 비교해 틀린 만큼 파라미터를 고친다. ➕ 이때 '틀린 정도'는 정답 토큰에 준 확률이 낮을수록 커지는 손실 함수(교차 엔트로피)로 계산하고, 경사 하강법으로 파라미터를 조정한다.

"싸늘하다. 가슴에 비수가 날아와"를 입력하면 처음에는 엉뚱한 토큰에 높은 확률을 줄 수 있지만, 정답 '꽂힌다'와 비교해 고치는 과정을 아주 많은 문장으로 반복하면 '꽂힌다'의 확률이 68%처럼 가장 높아진다.

## 5. 추론: 자기회귀 생성
학습을 마친 모델은 다음 토큰을 예측한다. ➕ 마지막 블록의 출력을 어휘 크기의 점수(logit)로 바꾸고 softmax로 확률 분포를 만든 뒤, 그 분포에서 토큰 하나를 고른다.

고른 토큰을 입력 뒤에 붙여 다시 다음 토큰을 예측하는 과정을 반복해 긴 답을 만든다. 챗GPT가 답을 한 단어씩 이어서 보여 주는 이유다.

## 6. 온도(Temperature)
온도는 다음 토큰 선택에 영향을 주는 하이퍼파라미터다. 온도 1이 기준이며, 낮추면 확률이 가장 높은 토큰이 주로 선택되어 답이 안정적이고, 높이면 확률이 낮은 토큰도 자주 선택되어 답이 다양해진다. 대신 사실이 아닌 내용을 만드는 환각(할루시네이션)도 늘어난다.

➕ 수식으로는 softmax에 넣기 전 각 logit을 온도 T로 나눈다: pᵢ = exp(zᵢ / T) / Σⱼ exp(zⱼ / T). T < 1이면 큰 값과 작은 값의 차이가 커져 분포가 뾰족해지고, T > 1이면 차이가 줄어 분포가 평평해진다.

## 7. 일반화와 모델 크기
모델은 문장을 통째로 외우지 않고 토큰 사이의 관계와 패턴을 학습하므로, 학습 예제에 없던 "My Name"에도 'is'처럼 자연스러운 다음 토큰을 예측한다.

GPT-2(small)는 파라미터 약 1억 2,400만 개의 작은 모델이라 요즘 대형 모델보다 출력이 어색하다. 대형 모델은 훨씬 많은 파라미터와 데이터로 학습하지만, 토큰 → 벡터 → 어텐션·MLP → 다음 토큰 확률 예측이라는 기본 원리는 같다.

➕ **생각해 볼 질문**: 어텐션 계산 비용은 입력 토큰 수가 늘면 어떻게 커질까? 모든 토큰 쌍의 점수(QKᵀ)를 구해야 한다는 점에서 생각해 보자.

## 낱말 풀이
| 낱말 | 뜻 |
|---|---|
| softmax | 점수 목록을 0~1 사이 값으로 바꾸어 합이 1인 확률 분포로 만드는 함수. pᵢ = exp(zᵢ) / Σⱼ exp(zⱼ) |
| Query·Key·Value | 어텐션에서 각 토큰이 만드는 세 벡터. Query와 Key로 관련도를 구하고, 그 가중치로 Value를 섞음 |
| logit | softmax에 들어가기 전, 각 후보 토큰에 매긴 점수. 온도는 이 값을 나누어 분포 모양을 바꿈 |

## 확인 질문
1. 어떤 문장에서 다음 토큰 후보의 logit이 정해져 있을 때, 온도를 1에서 0.5로 낮추면 확률 분포는 어떻게 되나요?
   ① 모든 후보의 확률이 같아진다 ② 가장 높은 후보의 확률이 더 커지고 분포가 뾰족해진다 ③ 가장 낮은 후보의 확률이 가장 커진다 ④ 분포는 변하지 않는다
2. 어텐션만으로는 토큰 순서를 구분하지 못하는 이유와, 트랜스포머가 이 문제를 어떻게 해결하는지 설명해 보세요.

### 정답(교사용)
1. ② (6절) — logit을 1보다 작은 T로 나누면 값 차이가 커짐
2. 어텐션은 토큰 쌍의 관련도로 가중합을 구할 뿐 위치를 쓰지 않으므로, 순서가 바뀌어도 같은 토큰 집합이면 순서 정보를 얻지 못함 → 각 토큰 임베딩에 위치 정보를 더하는 포지셔널 인코딩으로 해결 (3절 ①)
